# Diksha Shukla — Samsung Innovation Campus Portfolio

A responsive, single-page portfolio built with semantic HTML5, modern CSS and minimal vanilla JavaScript.

## Files

- `index.html` — page structure and content
- `css/style.css` — responsive visual system
- `js/script.js` — mobile navigation and reveal animations

## Run locally

Open `index.html` in a browser, or use VS Code + Live Server.

## GitHub Pages

1. Create a GitHub repository.
2. Upload the files while keeping the folder structure.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save and open the generated Pages URL.

## Important content note

The Samsung Innovation Campus section is intentionally written without unverified claims about specific modules, scores, certificates or awards. Replace/add those details only after confirming them.
